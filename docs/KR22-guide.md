# КР № 2. Интеграция React и Express

## Что сделано

1. В `client/` создано приложение Vite с React Router. Маршруты ведут на главную, историю, детальную страницу, вход и форму создания или редактирования.
2. `client/src/api.js` использует `fetch` и `VITE_API_URL`. Токен доступа остаётся в памяти вкладки. Запросы записи передают его в `Authorization`; после перезагрузки вкладки нужно снова войти.
3. Список поддерживает поиск, сортировку и пагинацию. На детальной странице отображаются номера исходных строк, добавления и удаления. Форма отправляет `POST` или `PATCH`. Удаление видно администратору.
4. Список и детали показывают загрузку и ошибки, пустая выдача имеет отдельное сообщение. При смене параметров предыдущий запрос отменяется.
5. Поиск ждёт 350 мс после последнего символа. Модули истории, деталей и редактора подключены через `React.lazy` и загружаются при переходах.

## Запуск двух частей

1. Настройте PostgreSQL и `.env` по [гайду КР № 1](KR21-guide.md). Укажите `PORT=33021` и добавьте `http://localhost:5173,http://127.0.0.1:5173` в `CORS_WHITELIST`.
2. В первом терминале из корня выполните `npm ci`, затем `npm start`.
3. Во втором терминале выполните `npm --prefix client ci` и `npm --prefix client run dev`. Адрес клиента напечатает Vite. Для другого адреса API скопируйте `client/.env.example` в `client/.env.local` и отредактируйте `VITE_API_URL`.
4. Для проверки оптимизаций в собранной версии выполните `npm --prefix client run build`, затем `npm --prefix client run preview -- --port 5173`.

## Что проверено в браузере

1. При вводе шести символов `README` с паузами меньше 350 мс выполнен один запрос с этим поиском.
2. На главной странице не загружался ни один из трёх модулей маршрутов. Переходы в историю, детали и редактор загружали соответствующие отдельные файлы.
3. Проверены загрузка с задержкой ответа, сообщение об ошибке и пустой результат. Создание вернуло 201, обновление — 200, удаление администратором — 204. Для обычного пользователя действие удаления отсутствовало.
4. Сборка Vite завершилась успешно.

## Облачные параметры

1. Для сервера импортируйте `render.yaml` в Render, привяжите ветку `kr22` и добавьте PostgreSQL, `DATABASE_URL` и `CORS_WHITELIST`.
2. Для клиента подключите репозиторий в Netlify и выберите ветку `kr22`. Команды сборки и перенаправление для прямых ссылок React Router определены в `netlify.toml`.
3. Добавьте в Netlify `VITE_API_URL` со значением HTTPS-адреса Render. Добавьте HTTPS-адрес Netlify в `CORS_WHITELIST` сервера и повторите сборку обеих частей.
4. После подключения проверьте прямую ссылку на вложенный маршрут и запросы к облачному API во вкладке Network.

Облачные проекты и постоянные адреса пока не созданы по согласованию. Рабочая проверка выполнена локально.
